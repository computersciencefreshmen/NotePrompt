# Product

## Register

product

## Users

NotePrompt serves individual developers, researchers, and content or operations professionals who repeatedly use AI for serious knowledge work. They need to turn working prompts into durable assets, compare and improve results, control model usage, and retrieve proven material without rebuilding context every time.

The primary workflow is personal production. A user captures or imports a prompt, structures and optimizes it in Prompt Studio, checkpoints meaningful versions, organizes it into one or more collections, and optionally publishes a deliberate snapshot for discovery.

## Product Purpose

NotePrompt is the personal production system for creating, optimizing, versioning, organizing, and deliberately publishing prompt assets. Success means that a user can move from rough intent to a reusable, trustworthy prompt without leaving one coherent workspace, while private content, AI cost, and publication state remain explicit and safe.

The product is intentionally a Next.js modular monolith for a single-owner, single-ECS operating model. It does not build Team workspaces, payments, real-time collaboration, Kubernetes, or enterprise workflow before the personal production loop is excellent.

## Brand Personality

Restrained, precise, trustworthy.

The interface speaks with calm expert confidence. It explains consequences before irreversible actions, exposes real system state, and avoids inflated claims. The visual character should feel like a carefully made professional instrument, not an AI spectacle.

## Anti-references

- Generic AI SaaS marketing built from purple gradients, glowing blobs, glass panels, and unsupported superlatives.
- Fragmented CRUD dashboards where creation, optimization, versions, publishing, and discovery feel like unrelated products.
- Four interchangeable visual skins that override one another and make component behavior unpredictable.
- Endless identical card grids, nested cards, decorative metrics, and modal-first workflows.
- Controls that imply saved privacy, notification, billing, or collaboration behavior when the backend does not persist it.
- Product copy that sells Pro, Team, or commercial capabilities which are only roadmap ideas.

## Design Principles

1. **One continuous production loop.** Creation, structured editing, AI optimization, comparison, checkpointing, and reuse belong to one Prompt Studio state model.
2. **Trust is visible behavior.** Ownership, privacy, publication, cost, save status, conflicts, and failures must be explicit and backed by real server state.
3. **Assets have stable identities.** A private prompt, a published snapshot, a curated template, an imported copy, and a collection membership are distinct concepts with one source of truth each.
4. **Progressive power.** The default path is focused and approachable; structured fields, model parameters, attachments, versions, and diagnostics expand when the task needs them.
5. **Operational truth over theatre.** Releases, health, quotas, and roadmap claims must reflect what is actually deployed and measurable.

## Accessibility & Inclusion

WCAG 2.2 AA is the default acceptance level. Every core workflow must support keyboard-only operation, visible and reliable focus, programmatic names, screen-reader status announcements, reduced motion, non-color state cues, and at least 44 by 44 pixel touch targets on mobile. Light and dark themes must both meet contrast requirements. Chinese and English interfaces must preserve meaning, layout resilience, and the document language attribute.
